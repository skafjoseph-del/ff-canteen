# Food Farmacy — Canteen Tick

Phone-friendly prep + handout checklist for school canteen day.

Loaded for Thursday 24 Sep 2026 (11 canteen orders, including Joel Rees / Maja).

**Live app:** https://skafjoseph-del.github.io/ff-canteen/

## Tabs
- Recess Prep / Lunch Prep — unit totals by item
- 11am recess / 1pm lunch — handout by family
- Observation report

Ticks, service moves, and notes save in the browser on each device (not synced live between phones).

Each unit of a multi-quantity line is its own checkbox. Snack products default to recess and other canteen items to lunch, but a line note or order note that says lunch or recess wins. On handout, **→ Lunch** / **→ Recess** moves that one unit and the prep counts follow.
